FAQ

Frequently asked questions.

What is Sleek?

Sleek is a minimalist design system for modern products. It provides semantic tokens, accessible components, and consistent patterns to help teams build better products faster.

How do I get started?

Install the package via npm, import the tokens and components, and you're ready to go. Check our documentation for detailed guides and examples.

Is Sleek accessible?

Yes. Every component is built to meet WCAG 2.2 AA standards, with keyboard-first interactions, visible focus states, and tested screen reader support.

Can I customize the tokens?

Absolutely. All tokens are exposed as CSS variables and can be overridden to match your brand. The 8pt spacing grid and semantic color tokens are designed to be extensible.

What support do you offer?

Starter plans include community support. Pro and Enterprise plans include priority support with guaranteed response times and dedicated Slack channels.

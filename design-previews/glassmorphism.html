// FAQ

Frequently asked questions

Everything you need to know about GlassUI.

GlassUI is a comprehensive glassmorphism design system that includes pre-built components, design tokens, and guidelines for building modern, accessible interfaces. It's built on open web standards and works with any framework.

Getting started is easy. Sign up for a free account, install the GlassUI package via npm or yarn, and import the components you need. Our documentation has step-by-step guides for every framework.

Yes. Every component in GlassUI meets WCAG 2.2 AA standards. We test with screen readers, keyboard navigation, and color contrast tools. Accessibility is not an afterthought — it's built into every component.

Absolutely. All design tokens — colors, typography, spacing, radii, and shadows — are exposed as CSS variables. You can override them in your own stylesheet to match your brand perfectly.

GlassUI is MIT licensed for the open-source components. Pro and Enterprise plans include additional proprietary components and features. You can use GlassUI in commercial projects without attribution.

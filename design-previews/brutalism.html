FAQ

Questions, answered.

What is brutalist design?

Brutalist design embraces raw, unpolished aesthetics inspired by 1950s concrete architecture. It prioritizes function over decoration, exposing structure and using bold, unadorned visual elements.

How do I migrate from my current design system?

Start by mapping your existing tokens to BRTL semantic tokens. Then replace components one by one. Our migration guide walks you through each step, and the drop-in replacement components make the transition seamless.

Do you support Figma?

Yes. The Pro plan includes a complete Figma library with all components, tokens, and design system documentation. It stays in sync with our code components.

What about accessibility?

Every component is WCAG 2.2 AA compliant. We test keyboard navigation, screen reader compatibility, color contrast, and focus states. Accessibility is non-negotiable.

Can I customize the tokens?

Absolutely. All tokens are CSS custom properties. Override them in your theme file. Change colors, spacing, typography — everything is customizable.

06 — FAQ

Frequently asked questions.

What is Basic?
Basic is a print-inspired design system for the web. It provides components, tokens, and patterns for building editorial-style interfaces.
How do I get started?
Sign up for a free account and you'll get access to all the core components and documentation. No credit card required.
Is Basic accessible?
Yes. Every component is built to WCAG 2.2 AA standards, with keyboard-first interactions, visible focus states, and screen-reader support.
Can I use Basic with my existing stack?
Absolutely. Basic is framework-agnostic and works with any modern JavaScript framework or plain HTML/CSS.
Do you offer custom design support?
Yes. Our Enterprise plan includes dedicated support and custom design system consulting for your team.

FAQ

Got questions? We've got answers.

Is RetroTech compatible with modern frameworks? +
Yes! RetroTech works with React, Vue, Svelte, and plain HTML. The components are framework-agnostic and can be dropped into any project.
Can I customize the color palette? +
Absolutely. All colors are exposed as CSS variables, so you can override them in your theme file. The design system is built to be extended.
Does it support dark mode? +
The vintage aesthetic is inherently dark-mode friendly. All components include dark mode variants out of the box.
How do I install RetroTech? +
Run npm install retro-tech or use the CDN link. Full installation docs are available in the getting started guide.

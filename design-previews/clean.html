Everything essential, nothing extra

Each feature is a deliberate choice — built on tokens, tested for accessibility.

Typography

Poppins for display, Roboto for body, Inconsolata for code. 12–32px scale, 8pt baseline.

8pt grid

Spacing is always a multiple of 8. Rhythm you can feel — no half steps.

AA contrast

Every text/background pair meets WCAG 2.2 AA. No exceptions.

Keyboard-first

Fully operable with tab, enter, space. Visible focus at all times.

Limited palette

6 semantic colors. No decorative gradients, no visual noise.

Sharp edges

Radius is always 0. Clean, honest, unambiguous geometry.

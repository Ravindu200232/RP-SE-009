FAQ

Answers to common questions.

What is Tetris DS?

Tetris DS is a comprehensive design system inspired by the iconic game. It includes components, tokens, and guidelines for building accessible, playful, and premium interfaces.

How do I install it?

Install via npm: npm install tetris-ds. Then import the CSS and components in your project.

Is it accessible?

Yes. Tetris DS is tested against WCAG 2.2 AA standards. Every component is keyboard-navigable and screen-reader friendly.

Can I customize it?

Absolutely. Use CSS variables to override colors, fonts, and spacing. Pro and Enterprise plans include custom theme support.

What's the license?

Tetris DS is MIT licensed. Use it in personal and commercial projects freely. Attribution is appreciated but not required.

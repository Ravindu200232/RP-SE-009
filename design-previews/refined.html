FAQ

Frequently asked questions

What exactly is included in the design system?

Refined includes 120+ production-ready components, a complete token system (colors, typography, spacing, shadows), Figma libraries, and comprehensive documentation. All components are WCAG 2.2 AA compliant and tested across modern browsers.

How does the theming system work?

Our theming system is built entirely on CSS custom properties. Change a token value once, and it propagates throughout your entire application. We support light, dark, and custom themes out of the box.

Can I use Refined with my existing tech stack?

Absolutely. Refined is framework-agnostic. We provide vanilla CSS, React, Vue, and Angular implementations. The token system works with any CSS-in-JS solution or preprocessor.

How often is the design system updated?

We release updates monthly, with major versions twice a year. Each release includes new components, improvements, and accessibility enhancements. You'll always have access to our changelog and migration guides.

What support options are available?

Starter plan includes community support via GitHub Discussions. Pro adds priority email support with 24-hour response time. Enterprise includes a dedicated support engineer and SLA-backed response times.

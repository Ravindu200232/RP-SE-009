FAQ

Frequently asked questions

What is Brutal?
Brutal is a neobrutalist design system built on Tailwind CSS. It provides pre-built components, design tokens, and tools that help teams create bold, accessible, and consistent user interfaces.
Is Brutal free to use?
Yes! The Starter plan is free forever and includes basic components under the MIT license. Upgrade to Pro for advanced features, priority support, and the Figma kit.
Can I customize the design tokens?
Absolutely. Brutal is built on Tailwind CSS, so you can override any token — colors, spacing, typography, and more — using the standard Tailwind config.
Is Brutal accessible?
Yes. Every component is built to meet WCAG 2.2 AA standards, including keyboard navigation, focus states, color contrast, and screen reader support.
Do you offer support?
Yes. Pro and Enterprise plans include priority support. Enterprise customers also get a dedicated support engineer and SLA.

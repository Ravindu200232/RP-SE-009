// faq

Frequently asked

Everything you need to know.

What is Neon?
Neon is a high-contrast design system for building bold, accessible interfaces. It provides semantic tokens, pre-built components, and a consistent visual language.
How do I install Neon?
Install via npm: npm install neon-design-system. Then import the CSS and start using components.
Is Neon accessible?
Yes. Every component is built to WCAG 2.2 AA standards, with keyboard-first interactions and visible focus states on all interactive elements.
Can I customize the tokens?
Absolutely. All colors, fonts, and spacing values are exposed as CSS variables. Override them in your theme file to match your brand.
Do you offer support?
Community support is free on our Discord. Pro and Enterprise plans include priority support with guaranteed response times.

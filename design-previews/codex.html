FAQ

Frequently asked questions.

What is Codex?
Codex is a radically minimal design system built around typography and whitespace. It provides a complete set of components, tokens, and guidelines for building clean, accessible interfaces.
Is Codex free?
Yes, the Starter plan is free forever. It includes 1 project and access to all basic components. Pro and Enterprise plans add more features and support.
Can I customize the tokens?
Absolutely. All design tokens are exposed as CSS variables. You can override colors, spacing, typography, and more to match your brand while keeping the system's structure.
Does Codex support dark mode?
Codex is designed as a light-first system. However, since all tokens are CSS variables, you can easily create a dark variant by swapping token values.

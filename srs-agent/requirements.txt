# What the SRS agent needs, and where it comes from.
#
# Nothing here needs installing on this machine: every package below was
# already present in the interpreter that runs server.py, which is why the SRS
# could be mounted in-process at all.
#
# Deliberately unpinned. The standalone srs-generator pins fastapi==0.115.0,
# uvicorn==0.30.6 and friends; the interpreter here has fastapi 0.136.3 and
# uvicorn 0.49.0, and the SRS runs on them unchanged. Reinstating those pins
# would downgrade the versions AgentForge itself is running under to satisfy a
# constraint the code does not actually have.
#
#   python -c "import fastapi, uvicorn, motor, httpx, sse_starlette, langgraph"
#
# is the whole check.

# ── Web framework ────────────────────────────────────────────
fastapi
uvicorn
python-multipart
sse-starlette

# ── Settings / validation ────────────────────────────────────
pydantic
pydantic-settings

# ── HTTP client (Ollama) ─────────────────────────────────────
httpx

# ── Agentic workflow ─────────────────────────────────────────
langgraph
langchain-core

# ── MongoDB (async) ──────────────────────────────────────────
motor
pymongo

# ── PDF + diagram artifacts ──────────────────────────────────
reportlab

# ── Optional. Each degrades gracefully when missing ──────────
# Installed here:
pypdf                 # read a PDF the user attaches
pillow                # image handling for OCR
pytesseract           # OCR, and only if the tesseract binary is also present
faster-whisper        # transcribes an attached recording; without it the
                      # upload is stored and a setup note is returned instead
pymupdf               # renders a PDF page the text layer could not read, so
                      # the vision model can read it. Without it a scanned PDF
                      # extracts to nothing, which is what it used to do.
# Not installed, and not required:
# pdfplumber          # a second PDF text extractor; pypdf covers the common case

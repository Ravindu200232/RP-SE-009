🚀 HOW TO USE
═══════════════════════════════════════════════════════════════════════════════

1. START THE BACKEND (learning engine initializes automatically):
   
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   uvicorn backend.main:app --host 0.0.0.0 --port 8004

2. RUN THE TESTS:
   
   pytest tests/test_learning.py -v -s

3. SEE IT IN ACTION:
   
   python example_learning_usage.py

4. QUERY FROM CODE (internal methods only):
   
   from backend.agent4.service import Agent4Service
   from backend.agent4.analytics import LearningAnalytics
   
   service = Agent4Service()
   summary = service.get_learning_summary()
   report = LearningAnalytics.generate_learning_report(summary)
   print(report)

🎓 INTERNAL METHODS (Backend-Only)
═══════════════════════════════════════════════════════════════════════════════

service.get_learning_summary()
  → Returns complete learning insights
  → Access pattern frequencies, distributions, trends

service.get_architecture_confidence_baseline(architecture)
  → Confidence statistics for an architecture
  → Useful for calibrating thresholds

service.get_recommended_stacks(architecture, limit=3)
  → Most common deployment profiles
  → Technology recommendations

service.get_framework_insights(architecture)
  → Service framework/runtime distribution
  → Trends for specific architectures

service.relearn_from_jobs(force=True)
  → Force re-analysis of all jobs
  → Useful after bulk uploads

LearningMonitor.check_learning_health(service)
  → Health status of learning engine
  → Diagnostics and statistics

LearningAnalytics.format_insights_for_admin(summary)
  → Format for internal dashboards
  → Admin-friendly output

LearningAnalytics.generate_learning_report(summary)
  → Generate text report
  → For documentation
